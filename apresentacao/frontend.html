Stack de Decisoes
Por que cada tecnologia
TecnologiaDecisaoJustificativa
React 18 Framework principal Concurrent features (Suspense, transitions), ecossistema maduro, componentes reutilizaveis para as 8 telas
Vite Build tool HMR instantaneo via ESM nativo, build de producao com Rollup, zero config para React JSX
Tailwind CSS 3 Estilo utility-first Sem CSS personalizado, design tokens no config, purge automatico elimina CSS morto em producao
Supabase BaaS + Storage PostgreSQL gerenciado, auth built-in, storage para fotos dos anuncios, SDK JS isomorfico
Framer Motion Animacoes API declarativa com variants, interoperavel com Tailwind, sem conflito com React DOM
Context API Estado global AuthContext suficiente para este escopo; evita overhead do Redux para SPA de 8 telas
Camada de Servicos
Os 7 servicos da aplicacao
authService
Cadastro, login, logout, recuperacao de sessao via Supabase Auth. Expoe signUp(), signIn(), signOut(), getUser()
listingsService
CRUD de anuncios — criacao com upload de fotos, listagem paginada com filtros (especie, estado, preco), busca por ID
proposalsService
Envio de proposta por comprador, listagem de propostas recebidas por produtor, aceite e recusa de proposta
logisticsService
Criacao de solicitacao de frete, listagem de cotacoes por solicitacao, aceite de cotacao pela transportadora
favoritesService
Adicao e remocao de anuncios favoritos, listagem de favoritos por usuario — tabela favoritos no Supabase
uploadsService
Upload de imagens para Supabase Storage bucket anuncio-fotos, retorno de URL publica assinada
notificationsService
Polling de notificacoes nao lidas por usuario, marcacao como lida — base para push notifications na v2

Decisoes Tecnicas
Tres escolhas que definiram o projeto
Supabase direto vs. API REST propria
Escolhemos: Supabase direto (frontend)
O cliente JS do Supabase faz queries tipadas diretamente ao PostgREST. Elimina a necessidade de um backend intermediario no prototipo. O Spring Boot existe como backend de producao, mas o frontend usa Supabase para agilidade. Row Level Security garante que cada usuario ve apenas seus proprios dados.
Tailwind utility-first vs. CSS modules
Escolhemos: Tailwind CSS
Velocidade de desenvolvimento sem troca de contexto entre JSX e CSS. Classes utilitarias com purge em producao resultam em bundle <5kb de CSS. Configuracao de design tokens (cores, tipografia, espacamento) centralizada em tailwind.config.js.
Framer Motion para UX
Escolhemos: Framer Motion
AnimatePresence para transicoes de tela, motion.div com variants para stagger de listas de anuncios. Animacoes declarativas no JSX sem imperativo CSS @keyframes. Performance via requestAnimationFrame nativo.
Roadmap Mobile
React para APK via Capacitor
A abordagem

O codigo React existente roda dentro de uma WebView nativa. Zero reescrita — apenas wrappers nativos Android/iOS.

# Instalar Capacitor
npm install @capacitor/core @capacitor/cli
npm install @capacitor/android

# Inicializar
npx cap init AgroPlace br.com.agroplace

# Build do React
npm run build

# Adicionar plataforma
npx cap add android

# Sincronizar e abrir no Android Studio
npx cap sync
npx cap open android
O que muda
Breakpoints
Revisao das classes Tailwind sm: e xs: para telas 360px
Touch targets
Botoes com min 44px de altura para conformidade HIG / Material
Camera
@capacitor/camera substitui o input[type=file] para upload de fotos dos animais
Push
@capacitor/push-notifications + Firebase Cloud Messaging para alertas de proposta
